# Mail — Interactive App Demo (Creator & Agency)

Interactive static showcase of the **Mail** content-marketing app using 100% fictional sample data (no real accounts, credentials, or personal data).

## Included Demos
- **Landing Hub (`/`)**: Overview & quick links to all demos
- **Mail Creator Demo (`/mail/`)**: 6 clickable pages (Dashboard, Multi-Platform Post, Comment Inbox, Direct Messages, Video Cutter, Marketing Analytics)
- **Mail Agency Demo (`/agency/`)**: 7 clickable pages (Multi-Brand Switcher, Cross-Client Calendar, Client Approval Portal, White-Label PDF Report, Crisis Inbox, Live Highlight Finder, Competitors & AI)
- **Analytics Charts Preview (`/charts/`)**: Interactive Best-Time Heatmap, Series Comparison, and Hook-vs-Views Scatter charts

## Deploy to Netlify
This repository includes `netlify.toml` (`publish = "."`). Connect it in Netlify or deploy with:
```bash
netlify deploy --prod --dir=.
```
